## P0：Web 机型区块 h3 定位（已完成）

**根因**：`findSectionHeading` 使用 `got.includes(want)`，「自动封边机」被「高速自动封边机」抢先匹配。

**改动**：`web/static/app.js`

- 新增 `machineSectionHeadingIndexAtOffset`、`answerBodyH3Elements`
- `findSectionHeading`：先 exact match；失败时用 markdown 中 `###` 序号对应 DOM h3（排除 References）

**验证**：重问 Q17，确认 `### 自动封边机` 下激光 bullet 后有图；高速自动区块不应叠两张激光图。

---

## P0.5：跨手册同 caption dedup + References 兜底（已完成）

**根因（Q16 透平油）**：答案无 `### 机型` 标题，三条 placement 均落 section `"_"`；三图 caption 相同 → 只保留第一张；inline 全失败时 `appendChild` 到答案容器末尾 → 图出现在 References 后。

**改动**：`web/static/app.js`（非领域词表）

- `imageDisplayDedupKey`：`source_key` 手册维度 + caption（caption 过短则用 URL）
- `appendFiguresToAnswerEnd`：有 `### References` 时在其 `h3` 前插入，否则仍 append 末尾
- `insertFigureAfterAnchor`：`marked breaks` 下多行 `<p>` 内按 `<br>` 行后插入（不再提升到整段 `<p>`）；批量插入逆序避免 DOM 漂移

**验证**：Q16 三机型各 1 张；Q11 三部件仍 3 张；Q17 各 `###` 区块行为与 P0 一致。

## P1：查询侧 sibling inline-figure 桥接（待做）

**根因**：灌库 `关联正文` 已绑定，但 retrieval/citation 引用的是无图 sibling chunk（如双端 `chunk-76122b630`、`chunk-3040519ad`），带 `740143cf` 的 `chunk-9e61a224` 未进 cited 池。

**方向**：复用 `_chunk_aligns_answer_bullet_via_inline_figure` 等现有对齐函数；限制在 cite_pool / cited_manual_kv_pool 内扩展。

---

## P2：灌库分段（待做，需重灌）

**根因**：`coalesce_text_image_segments` 只合并「紧后 `[图片]`」；双端 p7 表格版式下文字行先切 chunk，图挂在后续「轴承润滑」多图 chunk。

**方向**：同页相邻短 text segment 轻量合并后再 coalesce，或 `best_image_for_text_item` 结果回填到对应 text segment。

**注意**：改 ingest 关联后须重灌受影响手册（至少双端，可能含类似版式机型）。

---
