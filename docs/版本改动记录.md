**规模（提交当时）：** 15 个文件，+747 / −71 行。

### 代码改动（节选）

**1）问答配图：检索不够相关则不展示（`image_query_refs.py`）**

**改动目的（当时）：** 用户问「你好」「你弄啥嘞」等闲聊，或知识库无明确命中时，仍展示大量无关手册照片。

- `query_wants_kb_images()`：过滤纯寒暄/自我介绍类短句
- `retrieval_supports_images()`：rerank 最高分低于 `RAG_IMAGE_MIN_RERANK_SCORE`（默认跟随 `MIN_RERANK_SCORE` / 0.28）则不配图；无 rerank 分数时用查询词与检索正文命中率（`RAG_IMAGE_MIN_TERM_OVERLAP`，默认 0.34）
- 移除「分数不够也强行选一张图」的兜底逻辑
- `query_progress_hooks.py`：向 `images_for_api` 传入 `retrieved_docs`

**2）安装向导：追加灌库 vs 重新灌库（`setup.js` / `setup.html`）**

**改动目的（当时）：** 有旧库时「开始灌库」一律先清空，用户无法**只加新 PDF**；与「清空知识库」按钮语义重复。

- 知识库为空：**开始灌库**
- 已有文档：**追加灌库**（不清空）+ **重新灌库（清空后）**（确认后清空再写）
- 问答页 `app.js`：侧栏上传固定为追加语义，整批重灌引导回 `/setup`

**3）客户端 env：打包默认值 + 向导不冲掉调参项（`client_env_manager.py`）**

**改动目的（当时）：** 安装包无根目录 `.env`，`RAG_IMAGE_*` 等只在开发 `env.example` 里，客户/打包人员无法配置；向导保存时还会丢掉 `MIN_RERANK_SCORE` 等键。

- `CLIENT_TUNING_KEYS`：检索与配图相关键在客户端模式下持久化
- `apply_env_to_process()`：先加载 `config/env.example`，再加载 `config/.env` 覆盖
- `config/env.example` 增加 `MIN_RERANK_SCORE`、`RAG_IMAGE_MIN_RERANK_SCORE`、`RAG_IMAGE_MIN_TERM_OVERLAP` 等默认项

**4）灌库互斥与 UI 恢复（`rag_web_server.py` + `setup.js`）**

**改动目的（当时）：** 灌库进行中保存步骤 1 配置会打断 SSE，前端 `ingestBusy` 永久锁死；停止灌库后知识库可能半残。

- 灌库中拒绝 `POST /api/setup/env`、`/api/setup/reload-rag`（409）
- `/api/setup/status` 返回 `ingest_active`、`ingest_cancel_requested`；前端轮询服务端以解锁按钮
- 灌库异常且已请求取消时清空知识库并推送 `cancelled` 事件
- `_friendly_query_error()`：401/403 中文提示；`LLM_BINDING_API_KEY` 与 `OPENAI_API_KEY` 同步

**5）知识库计数：唯一 PDF vs 索引记录（`client_setup_service.py`）**

**改动目的（当时）：** 同一 PDF 灌 3～4 次后向导显示「22 篇文档」，实际只有 7 个 PDF，误导用户。

- `_unique_doc_paths()` 统计 `kv_store_full_docs.json` 中不同文件名
- 状态文案示例：`已灌库 7 个 PDF（索引记录 23 条，含重复灌库）`

### 使用提示（当时）

- **开发调试**仍主要改仓库根目录 `.env`；**打包交付**在 `config/env.example` 调好再 `pack_client.ps1`

def _flatten_table_text_for_skip_multimodal(
    self, items: List[Dict[str, Any]]
) -> str:
    """Collect table bodies for text-only ingest when multimodal stage is skipped."""
    parts: List[str] = []
    for item in items:
        if not isinstance(item, dict) or item.get("type") != "table":
            continue
        body = item.get("table_body")
        if isinstance(body, str) and body.strip():
            parts.append(body.strip())
            continue
        content = item.get("content")
        if isinstance(content, dict):
            html = (content.get("html") or "").strip()
            if html:
                parts.append(html)
    if not parts:
        return ""
    return "\n\n".join(f"[Table]\n{t}" for t in parts)

    """Resolve HF hub cache snapshot path for ``org/name`` (no network)."""
