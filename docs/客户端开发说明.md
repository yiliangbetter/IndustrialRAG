# 客户端开发与打包说明

面向 **绿色压缩包交付**（方案 A）、**安装包内置模型**、**浏览器安装向导**（方案 A）的技术说明。开发分支：`client-dev`。

## 客户看到的目录（交付物）

```text
NanxingRAG/
  NanxingRAG.exe              # 后续 PyInstaller 打包；当前可用 client_launcher.py
  runtime/                    # 打包后的 Python + 依赖（无业务 .py 源码）
  web/                        # 问答与安装向导静态页
  config/
    env.example
    .env                        # 向导生成
    setup_complete.json         # 完成标记
  data/
    models/                     # 内置 HF 模型（HF_HOME）
    rag_storage/                # 知识库
    pipeline_parse/             # 解析输出
  logs/
  README.txt
```

业务脚本（`query_doc_steering` 等）打进 `runtime`，**不要**随包分发 `scripts/*.py` 源码。

## 开发模式运行安装向导

在仓库根目录模拟客户端布局（使用 `config/`、`data/`）：

```powershell
uv sync --extra web --extra local-embed
uv run python scripts/client_launcher.py
```

浏览器会自动打开 **http://127.0.0.1:8765/setup**（未完成安装时）。

环境变量（可选）：

| 变量 | 说明 |
|------|------|
| `RAG_CLIENT_MODE=1` | 启用客户端模式（launcher 默认开启） |
| `RAG_CLIENT_APP_ROOT` | 安装根目录，默认仓库根 |

普通开发者模式（非客户端，直接问答）：

```powershell
uv run python scripts/rag_web_server.py
```

## 安装向导流程

1. **LLM 配置** — 表单写入 `config/.env`，保存后自动加载 RAG 引擎  
2. **环境检测** — Python 依赖、内置 bge-m3 / bge-reranker-base  
3. **灌库** — 上传 PDF 等，调用 `/api/ingest`  
4. **完成** — 写入 `config/setup_complete.json`，跳转 `/` 问答页  

相关代码：

| 模块 | 文件 |
|------|------|
| 路径布局 | `scripts/client_paths.py` |
| `.env` 读写 | `scripts/client_env_manager.py` |
| 检测逻辑 | `scripts/client_setup_service.py` |
| 启动器 | `scripts/client_launcher.py` |
| Setup API | `scripts/rag_web_server.py` → `/api/setup/*` |
| Setup UI | `web/setup.html`, `web/static/setup.js` |

## 内置模型（打包前准备）

开发阶段模型可能在仓库 `.hf_cache/`；交付时应复制到 `data/models/`：

```powershell
# 示例：将 HF hub 缓存复制到客户端 models 目录（打包脚本中自动化）
New-Item -ItemType Directory -Force -Path data\models\hub
Copy-Item -Recurse .hf_cache\hub\models--BAAI--bge-m3 data\models\hub\
Copy-Item -Recurse .hf_cache\hub\models--BAAI--bge-reranker-base data\models\hub\
```

安装向导会在 `data/models/hub/` 下检测 `snapshots/*/config.json` 与权重文件。

MinerU / PDF-Extract-Kit 权重体积更大，可按同样方式预置到 `data/models/` 或首次灌库前单独打包。
