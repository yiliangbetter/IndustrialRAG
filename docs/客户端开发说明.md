# 客户端开发与打包说明

面向 **绿色压缩包交付**（方案 A）、**安装包内置模型**、**浏览器安装向导**（方案 A）的技术说明。开发分支：`client-dev`。

## 客户看到的目录（交付物）

```text
NanxingRAG/
  NanxingRAG.exe              # 薄启动器（PyInstaller，推荐客户双击）
  NanxingRAG.bat              # 备用启动方式，与 exe 等价
  runtime/                    # 打包后的 Python + 依赖（客户无需自行安装）
  web/                        # 问答与安装向导静态页
  config/
    env.example
    .env                        # 向导生成
    setup_complete.json         # 完成标记
  data/
    models/                     # 内置 HF 模型（HF_HOME）
    rag_storage/                # 知识库
    pipeline_parse/             # 解析输出
  logs/
  README.txt
```

业务脚本（`query_doc_steering` 等）打进 `runtime`，**不要**随包分发 `scripts/*.py` 源码。

## 开发模式运行安装向导

在仓库根目录模拟客户端布局（使用 `config/`、`data/`）：

```powershell
uv sync --extra web --extra local-embed
uv run python scripts/client_launcher.py
```

浏览器会自动打开 **http://127.0.0.1:8765/setup**（未完成安装时）。

环境变量（可选）：

| 变量 | 说明 |
|------|------|
| `RAG_CLIENT_MODE=1` | 启用客户端模式（launcher 默认开启） |
| `RAG_CLIENT_APP_ROOT` | 安装根目录，默认仓库根 |

普通开发者模式（非客户端，直接问答）：

```powershell
uv run python scripts/rag_web_server.py
```

## 安装向导流程

1. **LLM 配置** — 表单写入 `config/.env`，保存后自动加载 RAG 引擎  
2. **环境检测** — Python 依赖、内置 bge-m3 / bge-reranker-base  
3. **灌库** — 上传 PDF 等，调用 `/api/ingest`  
4. **完成** — 写入 `config/setup_complete.json`，跳转 `/` 问答页  

相关代码：

| 模块 | 文件 |
|------|------|
| 路径布局 | `scripts/client_paths.py` |
| `.env` 读写 | `scripts/client_env_manager.py` |
| 检测逻辑 | `scripts/client_setup_service.py` |
| 启动器 | `scripts/client_launcher.py` |
| Setup API | `scripts/rag_web_server.py` → `/api/setup/*` |
| Setup UI | `web/setup.html`, `web/static/setup.js` |

## 内置模型（打包前准备）

开发阶段模型可能在仓库 `.hf_cache/`；交付时应复制到 `data/models/`：

```powershell
# 示例：将 HF hub 缓存复制到客户端 models 目录（打包脚本中自动化）
New-Item -ItemType Directory -Force -Path data\models\hub
Copy-Item -Recurse .hf_cache\hub\models--BAAI--bge-m3 data\models\hub\
Copy-Item -Recurse .hf_cache\hub\models--BAAI--bge-reranker-base data\models\hub\
```

安装向导会在 `data/models/hub/` 下检测 `snapshots/*/config.json` 与权重文件。

## 检索 / 配图等高级参数（给打包人员）

安装向导**只配置 LLM 等基础项**，不包含 `RAG_IMAGE_MIN_RERANK_SCORE`、`MIN_RERANK_SCORE` 等调参字段。

**交付前你在开发机调好、随包下发的做法：**

1. 编辑仓库内 **`config/env.example`**（打包脚本会复制到客户 `config/env.example`）。
2. 修改检索与配图相关项，例如：
   - `MIN_RERANK_SCORE` — 检索 rerank 过滤
   - `RAG_IMAGE_MIN_RERANK_SCORE` — 问答配图门槛（闲聊/低相关时不配图）
   - `RAG_IMAGE_MIN_TERM_OVERLAP` — 无 rerank 分数时的词命中率门槛
3. 重新执行 `scripts/pack_client.ps1` 打绿色包。

**运行时加载顺序：** `config/env.example`（默认值）→ `config/.env`（向导写入，可覆盖）。向导每次保存会把 `env.example` 中的调参项一并写入 `.env`，不会被冲掉。

**客户侧如需微调（少见）：** 用记事本编辑安装目录下 `config/.env` 中对应行，保存后重启 `NanxingRAG.exe`。无需也不应改 `env.example`（升级包可能覆盖）。

MinerU / PDF-Extract-Kit 权重体积更大，可按同样方式预置到 `data/models/` 或首次灌库前单独打包。

## 打包（P2）

在 **打包机** 上执行（需已 `uv sync --extra web --extra local-embed`，且模型已 staged 到 `data/models/`）：

```powershell
# 1. 若模型尚未复制到 data/models
scripts\stage_client_models.bat

# 2. 组装绿色目录 dist/NanxingRAG/（含离线模型 + runtime + web）
scripts\pack_client.bat

# 可选：同时打 zip（体积 10GB+，耗时长）
scripts\pack_client.bat -Zip -Force
```

脚本 `scripts/pack_client.ps1` 会：

1. 校验 `data/models/hub/` 下三套模型齐全（bge-m3、reranker、PDF-Extract-Kit）
2. 复制 `runtime/`（`.venv`）、`web/`、业务 `scripts/`、`data/models/`
3. 将 `raganything` 以 **非 editable** 方式装入 runtime（客户机路径无关）
4. 预生成 `config/tiktoken_cache/`（LightRAG 离线分词）
5. 写入 `NanxingRAG.bat`、`README.txt`

**客户侧离线保证：**

| 机制 | 说明 |
|------|------|
| `data/models/hub/` | 内置 HF 缓存，MinerU / embedding / rerank 均从此读取 |
| `HF_EMBED_OFFLINE=1` 等 | 客户端模式自动写入，禁止访问 huggingface.co |
| `TIKTOKEN_CACHE_DIR` | 打包时预缓存，避免 tiktoken 联网 |

客户只需能访问 **LLM API**（安装向导填写），**不需要** Hugging Face。

**客户是否需要命令行？** 不需要。交付包已含 `runtime/`（完整 Python 与依赖）和内置模型；客户解压后双击 `NanxingRAG.exe` 即可，全程在浏览器完成配置与灌库。`uv sync` / `pip install` 等仅开发机打包时使用。

### 参数

| 参数 | 说明 |
|------|------|
| `-Force` | 覆盖已有 `dist/NanxingRAG` |
| `-Zip` | 额外生成 `dist/NanxingRAG.zip` |
| `-SkipModels` | 跳过复制模型（调试用） |
| `-SkipVenv` | 跳过复制 runtime（调试用） |
| `-SkipExe` | 不生成 `NanxingRAG.exe`（仅 bat） |

### 启动器说明（方案 A）

| 文件 | 作用 |
|------|------|
| `NanxingRAG.exe` | PyInstaller 薄启动器，设置离线环境变量后调用 `runtime/Scripts/python.exe` |
| `NanxingRAG.bat` | 同等逻辑，供 exe 被拦截时的备用 |
| `scripts/client_launcher_exe.py` | exe 源码，打包时由 `pack_client.ps1` 调用 PyInstaller |

exe **不包含** torch/MinerU，体积约数 MB；大体积依赖仍在 `runtime/` 与 `data/models/`。
